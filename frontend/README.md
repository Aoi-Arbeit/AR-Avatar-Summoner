# Frontend

React、TypeScript、Vite、Three.js を使ったキャラクター作成画面です。全体の進捗は [プロジェクト README](../README.md) を参照してください。

## セットアップと起動

Node.js と npm が必要です。フロントエンドのディレクトリで実行します。

```sh
cd frontend
npm install
npm run dev
```

通常 `http://localhost:5173` で表示します。バックエンドを `http://localhost:8000` で起動すると、Vite の開発サーバーが `/api` を転送します。バックエンドの DB 初期化については [backend/README.md](../backend/README.md) を参照してください。

```sh
npm run build    # TypeScript 検査と Vite ビルド
npm run preview  # ビルド済みファイルのプレビュー
```

`preview` は開発サーバーの API プロキシと同じ構成ではありません。今回、依存関係のインストール、ビルド、ブラウザ起動は検証していません。

## 実装状況

- 作成画面には名前、人格、パーツ、髪色の入力と、保存 API の呼び出しがあります。
- Three.js のプリミティブ図形による仮のアバターと回転操作があります。現状、描画は初回選択値で作られ、後からパーツや髪色を変えても反映されません。顔・体などは仮モデルに十分反映されておらず、GLB のパーツ結合も未実装です。
- AI 提案画面は `prompt` を送りますが、バックエンドは `instruction` を要求するため、現在は正常に連携しません。アクセサリーの提案結果も画面選択へ変換されません。
- スマートフォン用のログイン、AR、カメラ、音声機能は未実装です。保存結果の QR は仮 URL であり、AR 召喚先として使えません。

## 注意事項

QR 画像は外部サービス `api.qrserver.com` を利用しています。画像を読み込むと、ID とアクセスコードを含む QR 用 URL が同サービスへ送信されます。実際の秘密情報では利用しないでください。自動テストはリポジトリ内にありません。
